## Key Insights From Research Phase

### 1. Funnel (3-stage, not 2)
- Uploaded: 4,453 → Created: 14,916 → Published: 111
- 3.35× multiplier (Upload→Create): AI working correctly
- Count publish rate: 0.74% | Duration publish rate: 0.32% (worse — nobody else computes this)
- 1,350.8 hours of AI-processed content never reached a viewer

### 2. Data Quality Findings (no other team will have these)
- 99.3% Unknown team names — systemic pipeline failure
- 68% of published videos have no URL/platform recorded
- QA contamination: 29.2% of all created content (QA-Purushottam = 2nd biggest "user")
- Channel label mismatch: CLIENT_1_combined ≠ channel-wise-publishing.csv (same numbers, different labels)
- My Key Moments: 2.59% publish rate vs 0.74% avg — 3.5× better

### 3. Duration Analysis (the missing axis)
- Avg created clip: 5.5 min | Avg published clip: 2.5 min
- Clients only publish SHORT clips (Reels, Shorts, My Key Moments)
- Long-form outputs ignored: Chapters 0.10%, Summaries 0.12%
- COUNT ↔ HOURS toggle required on every chart

### 4. Platform Coverage Index (Frammer's real value prop)
- metric: total_platform_publishes / unique_published_videos
- Channel D: ~5.0 (multi-platform, ideal client)
- Channel A: ~1.3 (mostly single-platform)
- This IS the value proposition of Frammer working vs not working

### 5. Multi-tenant Signal
- CLIENT_1_combined_data_... naming signals B2B multi-tenant platform
- Need client switcher pill in nav
- CLIENT_2 (Entertainment): 1.7% publish rate benchmark
- CLIENT_3 (Sports): 0.24% publish rate (large client, no SLA)

### 6. Architecture Decisions (final)
Stack: LangGraph + LangChain + langchain-mcp-adapters → MotherDuck MCP → DuckDB
Agent graph: router → interpret → execute → narrate (4 nodes)
Custom MCP servers via FastMCP: kpi_server, alert_server, report_server
SQL pattern: SQL-of-Thought (arXiv:2509.00581) — local ref in draft/SQL-of-Thought-main/
Forecasting: Chronos-Bolt-Tiny (9M params, zero-shot) for upload counts
Anomaly detection: River HalfSpaceTrees (real-time, per-event)
Personas: Leadership (CEO/Manager) | Creator (Editor/Uploader)
Extensibility: YAML metric registry — add KPI via YAML entry + SQL file, zero code change

### 7. Ambient Agent Architecture
3 always-running agents:
- Monitor (cron 6h): publish rate vs baseline → Notify/Review to Agent Inbox
- Intake (new row trigger): missing team_name, missing URL → Question to inbox
- Reporter (cron 1st of month): generate_client_brief → Review → send on approval

HITL modes (Agent Inbox UI):
- Notify: fire alert, no approval
- Question: ask user before external notification
- Review: surface insight for human decision
